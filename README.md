# Hello World

## Description

This project is a simple Hello World webpage created as an introduction to web development. The page was built using HTML5 and deployed using Netlify.

The webpage includes semantic HTML elements, an image, and metadata
in the HTML `<head>`.

## Technologies

- HTML5
- Git
- GitHub
- Netlify

## Features

- HTML5 document structure
- Semantic HTML elements
- Hello World heading and content
- Image
- Metadata in the `<head>`
- Comments explaining the metadata
- Netlify deployment
